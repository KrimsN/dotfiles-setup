# modules/zsh.sh

Устанавливает zsh (через `os::pkg_install`), oh-my-zsh (неинтерактивно:
`RUNZSH=no CHSH=no`), Powerlevel10k и три внешних плагина
(zsh-autosuggestions, fast-syntax-highlighting, zsh-completions) через
`git clone --depth=1` в `$ZSH_CUSTOM`, пишет `~/.zshrc` из `config/zshrc`
(с бэкапом старого файла при отличии — сравнение через `cmp`; т.к.
`diffutils` не всегда стоит в минимальных образах, модуль сам ставит его
перед сравнением через `os::pkg_install diffutils`, идемпотентно) и
опционально делает zsh login-shell'ом по умолчанию через `chsh` — вопрос
задаётся через `/dev/tty` (`zsh::_want_default_shell`) по схеме из
"Механизм конфигурации" в CLAUDE.md, с env-override
`ZSH_DEFAULT_SHELL=yes|no` и безопасным дефолтом "no" без интерактива.

Требует зависимость `scripts/lib/os-detect.sh` (использует
`os::pkg_install`) — подключать оба через `source` в этом порядке.
Идемпотентен: повторный запуск ничего не переустанавливает и не трогает
уже применённый login-shell (проверка через `getent passwd`, а не
`$SHELL`, т.к. переменная не обновляется до перелогина).

`config/zshrc` дополнительно содержит (сверено с рабочим `~/.zshrc` из
реальной WSL-настройки):
- кэш автодополнения (`zstyle ':completion:*' use-cache on` +
  `cache-path`), выставляется до `compinit` (запускается внутри
  `oh-my-zsh.sh`);
- расширенные настройки истории (`HISTSIZE`/`SAVEHIST=50000`, общая
  история между сессиями, дедупликация, поиск по префиксу на
  стрелках вверх/вниз);
- интеграция fzf/zoxide с шеллом, guard'ится через `command -v` (не
  зависит от того, ставился ли `cli-tools.sh`). Для fzf — двухступенчатый
  фолбэк: сначала пробует `fzf --zsh` (флаг появился в fzf 0.48, 2024),
  и только если бинарник его не поддерживает (например версия из apt на
  Ubuntu 24.04/Debian 12 — там `0.44.1`), source'ит пакетные скрипты
  `/usr/share/doc/fzf/examples/{key-bindings,completion}.zsh`. В
  минимальных Docker-образах (`ubuntu:24.04` и т.п.) эти файлы вырезаны
  дистрибутивом ради размера образа — тогда fzf остаётся без байндингов,
  но шелл стартует без ошибок; на реальной машине (проверено на WSL
  Ubuntu) файлы есть и биндинг `^R` → `fzf-history-widget` подключается.

**Тестирование**: end-to-end в контейнерах Ubuntu 24.04 и Fedora 39,
включая двойной запуск для проверки идемпотентности. Отдельно
перепроверено (2026-08-25, Ubuntu 24.04, модули `base cli-tools aliases
zsh`) после добавления истории/кэша/fzf-zoxide: двойной прогон
`install.sh`, чистый `zsh -ic` без вывода на stderr, `type z` находит
функцию zoxide, `$(fzf --zsh)` корректно проваливается в fallback на
apt-версии 0.44.1.
