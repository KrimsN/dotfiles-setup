# scripts/lib/localbin.sh

`localbin::ensure_path` — единственный автор снипета
`~/.config/knrc/path.sh`, который добавляет `~/.local/bin` в PATH
(подключается условной строкой из `config/zshrc` и управляемым блоком
`knrc:localbin-path` в `~/.bashrc`). Кроме записи на диск функция
экспортирует PATH и в текущем процессе — чтобы то, что ставится дальше в
этом же прогоне, находилось без перелогина (`uv` → `uv tool install
ruff`).

Раньше снипет писал `modules/python-tools.sh` ради `uv`/`ruff`. Он
вынесен сюда, когда в тот же каталог добавился лаунчер `knrc`
(см. [doctor.md](doctor.md)): каталог нужен в PATH независимо от того,
выбран ли модуль python-tools, а два разных писателя одного файла — это
гарантированный рассинхрон. `install.sh` вызывает `localbin::ensure_path`
до установки модулей, `python_tools::install` — между `uv` и `ruff`.

`~/.local/bin`, а не `/usr/local/bin`: не требует sudo и ничего не кладёт
в системные каталоги.

Миграция уже настроенных машин: старый блок `knrc:python-tools-path`
удаляется через `rcfile::remove_block` (см. [rcfile.md](rcfile.md)),
иначе он остался бы в `~/.bashrc` и сорсил бы тот же файл повторно.

**Тестирование**: в составе полного прогона `install.sh` на Ubuntu 24.04
(два запуска в одном контейнере) и через `knrc doctor`, который отдельно
проверяет и снипет, и блок в `~/.bashrc`, и наличие каталога в PATH.
